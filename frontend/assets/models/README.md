# 3D model attribution

`michelle.glb` is the Michelle character distributed in the official Three.js
examples repository. The character and its animations originate from Adobe
Mixamo.

- Source: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Michelle.glb
- Mixamo usage terms: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Adobe states that Mixamo characters and animations may be used royalty-free in
personal, commercial, and non-profit projects. The model is embedded only as an
application asset and is not offered separately for redistribution.
