# Modelo de qualidade

Quality é multidimensional: cobertura/registro de câmera, erro de reprojeção, geometria válida, completude, fidelidade visual, referência dimensional, confiança de categoria e readiness para composição. O modelo não reduz critérios a uma nota única. `geometry_confidence` e `texture_confidence` permanecem ausentes até experimento físico; medida declarada é `DECLARATION_NOT_METROLOGY`.
