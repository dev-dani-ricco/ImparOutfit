# Golden Path — preparação CICLO 3A

O app em modo API apresenta: experimentar, avatar experimental, primeira peça, captura, processamento retomável, armário, Look, visualização/comparação e Dani Digital como etapa futura. Jobs são consultados novamente ao voltar ao app; `QUEUED` e `PROCESSING` não bloqueiam o restante do armário. `NEEDS_MORE_INPUT` mostra a recaptura parcial necessária. Nenhuma tela trata um job não aprovado como READY.
