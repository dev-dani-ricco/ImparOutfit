# Private Knowledge Governance

Private Source is metadata only and never equals institutional knowledge. Source creates Candidate; Candidate enters review; an explicit Principal review approves or rejects it; only a separately authorized publication creates an immutable AuthorizedKnowledgeVersion. Private references and content never appear in API responses.

Only published AuthorizedKnowledgeVersions bind explicitly to a DRAFT MethodologyVersion. No latest selection exists; published methodology bindings are immutable. PERSONAL knowledge ingestion is not implemented; the schema only permits IMPAR scope, forming the initial firewall. RAG, embeddings, retrieval and AI are not implemented.
